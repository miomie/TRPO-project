# Веб-приложение «Карьера» — учебная версия

## Запуск
1. Распакуйте архив целиком, не перемещая папку `images`.
2. Откройте папку проекта в Visual Studio Code.
3. Запустите `index.html` через расширение **Live Server** (рекомендуется).
4. Данные сохраняются в `localStorage` браузера. Для сброса демонстрационных данных очистите хранилище сайта в DevTools или удалите ключ `career_platform_db_v1`.

Можно открыть `index.html` напрямую, но для корректной работы всех функций рекомендуется локальный HTTP-сервер (Live Server).

## Страницы
- `index.html` — главная страница и быстрый поиск.
- `auth.html` — вход и регистрация с выбором роли.
- `vacancies.html` — каталог вакансий, поиск и фильтры.
- `applicant.html` — кабинет соискателя, резюме, отклики и подборка вакансий.
- `employer.html` — кабинет работодателя, управление вакансиями, отклики и база резюме.
- `style.css` — адаптивные стили.
- `script.js` — логика приложения и LocalStorage.
- `base.json` — исходные демонстрационные данные (структура соответствует модели проекта).

## Основные сценарии
- Зарегистрировать аккаунт как «Я ищу работу» или «Я ищу работников».
- Соискатель создаёт резюме и откликается на опубликованные вакансии.
- Работодатель создаёт/редактирует/приостанавливает вакансии.
- Работодатель просматривает отклики по своим вакансиям, фильтрует их и меняет этапы.
- Работодатель просматривает базу активных резюме и фильтрует по должности, навыкам, городу и опыту.
- Изменения автоматически сохраняются в LocalStorage.

## Важное ограничение учебной реализации
Это клиентский прототип без серверной части. LocalStorage хранит данные только в текущем браузере и не обеспечивает синхронизацию между разными устройствами/пользователями. Пароли в такой демонстрационной версии не защищены серверным хешированием. Для реального внедрения необходим backend, база данных, серверная авторизация и безопасная загрузка файлов.
